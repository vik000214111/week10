# 🌄 Landscape Generator

An interactive web application that creates beautiful landscape scenes by combining three elements: Sky, Ground, and Atmosphere.

## Features

- **Sky Options**: Clear, Cloudy, Sunset, Starry, Storm
- **Ground Options**: Sand, Forest, Ocean, Grassland, City
- **Atmosphere Options**: Fog, Light, Rain, Wind, Fireflies
- **Immersive Audio**: Environmental sounds that match your scene (rain, wind, ocean waves, birds, crickets, thunder)

## How to Use

1. Open `index.html` in your web browser
2. Click **"Sound On"** button to enable environmental audio (optional but recommended!)
3. Click on options from each category to create your landscape
4. See the scene update in real-time with matching sound effects
5. Use the **"Random Scene"** button to generate random combinations
6. Click **"Save Landscape"** to download your creation

## Example Combinations

- 🌌 **Starry sky + Ocean + Fireflies** → A romantic night scene
- 🌃 **Storm + City + Fog** → A post-apocalyptic atmosphere
- 🌾 **Clear sky + Grassland + Wind** → A refreshing scene
- 🌅 **Sunset + Ocean + Light** → A golden hour paradise
- 🌲 **Cloudy + Forest + Rain** → A peaceful rainy forest

## Audio Effects

Different scenes trigger different environmental sounds:

- **Rain atmosphere** → Realistic rainfall sounds
- **Wind atmosphere** → Howling wind ambience
- **Ocean ground** → Gentle wave sounds
- **Forest ground** → Birds chirping
- **Starry sky** → Night crickets
- **Storm sky** → Thunder and heavy rain

All sounds are procedurally generated using Web Audio API - no external audio files needed!

## Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript
- Web Audio API (for procedural sound generation)
- html2canvas (for saving images)
